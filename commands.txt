── First-time setup ──────────────────────────────────────────────────────────

  python3 -m venv .venv            # create local venv
  source .venv/bin/activate        # activate it
  pip install -r requirements.txt  # install deps
  python3 main.py                  # run on default port (8765)
  python3 main.py --port 9000      # run on a custom port

── Every subsequent session ─────────────────────────────────────────────────

  git pull                         # get latest code
  source .venv/bin/activate        # activate venv
  pip install -r requirements.txt  # pick up any new deps
  python3 main.py --port 9000      # run on a custom port

── When done ────────────────────────────────────────────────────────────────

  deactivate                       # exit venv

── Open in browser ──────────────────────────────────────────────────────────

  http://localhost:9000            # (or whatever port you chose)

── Port conflict? ───────────────────────────────────────────────────────────

  lsof -i :8765                    # see what's using a port
  python3 main.py --port 9000      # just pick a free port
